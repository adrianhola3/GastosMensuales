Cada lectura se sella, se archiva y se puede citar en un informe. El dispositivo no aprende: mide, y lo que mide no cambia según quién mire.

01 · Calibración

La referencia no se vence

El sensor se autocompara contra una referencia interna cada 90 días. La desviación se corrige sola y queda registrada. No existe la tarea anual de "recalibrar el equipo".

02 · Registro

Cada lectura tiene sello de tiempo

El registro es inmutable. Puedes compartir el enlace de una lectura concreta, no un export genérico con fecha de modification. Nadie edita la historia.
