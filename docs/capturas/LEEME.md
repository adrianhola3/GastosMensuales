# Capturas de referencia

Imagenes de referencia y evidencia de sesiones de diseno anteriores: comparaciones
de referencia (`refero-*`, `pauta-*`), estados de WhatsApp (`wa-*`,
`whatsapp-estado*`), demos del tema (`demo-*`) y pares antes/despues.

**La aplicacion no las usa.** Ningun archivo de `index.html`, `js/` o `css/` las
referencia: estan aca como documentacion visual, no como assets del sitio. Se
movieron desde la raiz del repositorio porque ensuciaban cada `git status` sin
aportar nada a la app.
